# Legacy experiments

These scripts belong to earlier experimental versions and are not used to
support the revised EPSR manuscript.

Legacy scripts from earlier research versions are not included in the current
EPSR-supported snapshot. Some remain accessible through the repository's public
Git history, but they are not part of the workflow or experimental evidence
supporting the present manuscript. The supported inspectable examples are in
`examples/`; current data provenance is in `data/README.md` and
`docs/DATA_PROVENANCE.md`.
