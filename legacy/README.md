# Legacy experiments

These scripts belong to earlier experimental versions and are not used to
support the revised EPSR manuscript.

The scripts themselves are kept in the authors' private provenance archive,
not in this public repository. This avoids exposing obsolete DR settlement,
tariff BESS, Case B/risk-aware MPC, guard/fallback and interval routes as
support for the current paper. The supported inspectable examples are in
`examples/`; current data provenance is in `data/README.md` and
`docs/DATA_PROVENANCE.md`.
